StudyAI · Privacy & Data

Collect less. Explain what is saved.

StudyAI is an independent student-built learning project. This page describes the data behavior implemented in the current application so students can understand what stays in their browser, what can be synced to an account, and what is sent to external AI services.

Browser-local study data

StudyAI is local-first. When you use the site, supported learning state can be stored in your browser, including progress, mastery evidence, wrong answers, flashcard schedules, plans, bookmarks, Workspace notes, and study preferences.

Clearing browser storage can remove local-only data. When you are signed in, supported StudyAI state can also sync to your account database.

Account data

If you create an account, StudyAI stores the minimum account information needed for the current sign-in system:

  • name, if supplied;
  • email address;
  • a securely hashed password for email/password accounts;
  • provider identifiers for any configured social sign-in provider;
  • your synced StudyAI learning state.

Passwords are not stored as plain text.

Private-beta product signals

To understand whether StudyAI is useful during the controlled beta, the synced study state can include a small set of product signals: distinct active days, first recorded practice time, guided sessions started and completed, and last-active time.

These signals are used to evaluate whether students return and complete learning actions. StudyAI does not need a school name, phone number, street address, precise location, or date of birth for these beta signals.

External services and sign-in

StudyAI can load the College Board testing versions of the Desmos graphing and scientific calculators inside the SAT tools. Loading those embedded Desmos pages creates a direct browser connection to Desmos and is subject to Desmos's applicable privacy practices.

If a social sign-in provider is configured, StudyAI can use Google, Microsoft, or Apple authentication. The provider handles its own sign-in screen and returns the account information needed to link the StudyAI identity. Providers that are not configured remain unavailable.

StudyAI is an independent project and is not affiliated with Desmos, College Board, Google, Microsoft, or Apple.

Personal AI

Personal AI source documents are intentionally kept in browser storage rather than added to normal account-state sync. When you choose an AI action, the selected source text and your request are sent from the StudyAI server to Google's Gemini API so the requested output can be generated.

Avoid uploading passwords, medical records, financial records, private identifiers, or other sensitive material. External AI processing is governed by the provider's applicable API terms and policies.

Question-quality reports

If you use “Report question,” StudyAI may save the question text, surrounding context, the category you selected, optional comments, the page/feature where the report came from, and your account ID if you were signed in. These reports are used to improve question quality.

Session cookies and security

Signed-in sessions use an HTTP-only session cookie. The application is configured for SameSite=Lax cookies and supports secure-only cookies for HTTPS production deployments. Security headers and same-origin checks are applied by the server.

Reliability diagnostics

During beta preparation, StudyAI can record a minimal browser error report when the interface crashes: the error message, script filename, line and column, current page section, timestamp, and account ID if signed in. The diagnostic reporter is intentionally limited and does not collect note text, question responses, Personal AI source documents, or page contents.

Your controls

When signed in, open the account panel to:

  • Download my data to export your current account information and synced StudyAI state as JSON.
  • Delete account to permanently remove the account and its synced state from StudyAI's database.

Signing out does not delete the server-side account. Account deletion is a separate action and requires an explicit confirmation.

What StudyAI does not need

The current product does not require your phone number, street address, precise location, school name, or date of birth to use its core study features.

Project status

StudyAI is being prepared for a controlled private beta. This page should be reviewed again before any wider public launch, especially if hosting, analytics, authentication, or third-party services change.
